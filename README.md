# Full Stack Car Dealership Review Application

## Project Overview

A full-stack web application developed as part of the IBM Full Stack Developer Capstone Project. It enables users to explore car dealerships, view dealer information, read customer reviews, register and log in, and submit reviews.

## Technologies Used

- **Frontend:** React, HTML, CSS, JavaScript
- **Backend:** Django, Python, Node.js
- **Database:** SQLite and MongoDB
- **Tools:** Git, GitHub Actions, cURL

## Key Features

- User registration, login, and logout
- View all car dealerships and filter dealerships by state
- View dealership details and customer reviews
- Submit reviews and analyze their sentiment
- Automated workflow testing and application deployment
